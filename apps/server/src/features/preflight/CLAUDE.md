# preflight

In-memory snapshot: startup and demo reset `runChecks()`, `GET /api/preflight` never rebuilds (503 if unset), `POST /api/preflight/recheck` invalidates `gh:status` and Claude config then rebuilds. Saving a GitHub token in Settings stores the secret only — it does not patch the in-memory preflight GitHub check row. `pnpm preflight` is a separate process and still runs checks. Exits non-zero on required failures. Required: Node, pnpm, git (>=2.20; worktrees since 2.5), GitHub token, Claude, SQLite schema. Optional: Jira (warn). Demo (`FLIGHTDECK_DEMO=1`) fakes pass; `FLIGHTDECK_PREFLIGHT=fail` or `POST /api/demo/preflight` shows failures. No secrets in keys or logs.
