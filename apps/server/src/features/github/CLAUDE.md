# github

Octokit (`@octokit/rest` + throttle + retry) for GitHub API. Throttle callbacks return false so `withBackoff` (30s cap) owns retries. git CLI stays for clone/fetch/worktree/commit/push, authenticated via `GIT_ASKPASS` (copied to `~/.flightdeck/askpass.mjs` at 0700) — never a token in remote URLs or `.git/config`. Token: `GITHUB_TOKEN`, else `GH_TOKEN`, else keychain (`@napi-rs/keyring`) or `~/.flightdeck/secrets/github-token` (0600). Never log or persist the env token. `GIT_ASKPASS` gets the resolved token. Settings save stores the PAT only — no `GET /user`. `GET /user` is preflight-only (`checkGithub`). Issue sync uses `resolveGithubToken` and `listAssignedIssues` (401/403 = skip). Demo mode uses `createDemoGithubClient`. Cache keys `gh:status` / `gh:issues` / `gh:repos` keep existing TTLs. `POST /api/preflight/recheck` drops `gh:status`.
